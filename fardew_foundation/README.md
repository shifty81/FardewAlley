# Fardew Alley Missing Foundations Pack

This pack fleshes out the missing project foundations and includes starter C++ code for:

- world model
- tile schema
- item and crop data
- inventory
- player state
- interaction result pipeline
- split-screen co-op rules
- save root and serializer stub

## Entry point
- `Source/Fardew/main.cpp`

## Notes
This is a clean starter pack, not the full game.
It is designed to stop schema drift and let later systems plug into a stable foundation.
