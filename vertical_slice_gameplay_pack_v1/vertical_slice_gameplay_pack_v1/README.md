# Vertical Slice Gameplay Pack v1

Native C++ skeleton for a 2D top-down split-screen co-op vertical slice.

Included systems:
- tilemap definitions and loader stub
- collision grid
- interaction system with exclusive locks
- farming tile state and day tick
- chest lock rules
- dialogue lock rules
- basic HUD rendering hooks
- top-level gameplay update wiring

This pack is intentionally minimal and implementation-oriented.
